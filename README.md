# PricePilot

Price comparison and price history platform built using the MERN stack.

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- Axios

## Current Features

- React frontend
- Express backend
- MongoDB Atlas connection
- Product API
- React to Express API communication

## Project Structure

```text
client/
    React frontend

server/
    Express backend
```
